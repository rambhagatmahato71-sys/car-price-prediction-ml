🚗 Car Price Prediction ML Model

About the Project

This project predicts the estimated selling price of a used car using Machine Learning and Streamlit.

Features

- Select car brand
- Enter manufacturing year and kilometers driven
- Select fuel type, transmission, and owner type
- Enter mileage, engine capacity, and maximum power
- Predict the estimated selling price

Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Machine Learning

How to Run

1. Install Python.
2. Install the required libraries.
3. Run the Streamlit application:

streamlit run app.py

Project Files

- "app.py" — Streamlit application
- "Cardetails.csv" — Car dataset
- "model.pkl" — Trained machine learning model
- "Untitled.ipynb" — Jupyter Notebook

Disclaimer

Predicted prices are estimates and may differ from actual market prices.
